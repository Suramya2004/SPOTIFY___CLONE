Spotify Clone
This project is a front-end clone of Spotify, built with HTML, CSS, and JavaScript. It features a responsive user interface, mimicking Spotify's design and functionality. Key features include:
•	Responsive Design: Ensures the layout adjusts to different screen sizes, offering a seamless experience on both desktop and mobile devices.
•	Custom Playlists Section: Displays several curated playlists, each represented by a card with an album cover, playlist name, and description.
•	Interactive Playbar: Includes play, pause, and song control buttons, as well as a volume slider to simulate media control functionality.
•	Login and Signup Buttons: Although non-functional, these buttons give the interface a more authentic look.
•	Dynamic Icons and Styling: Uses SVGs and custom CSS for a polished look and feel.
The project primarily focuses on replicating the look of the Spotify web player, using CSS for styling and JavaScript for interactive elements.

Features:
•	Responsive layout for both mobile and desktop
•	A sidebar for navigation (Home, Search, and Library)
•	Playlist display with album covers and descriptions
•	Playbar with song controls (previous, play, next)
•	Buttons for signing up and logging in
•	Dynamic media queries to ensure adaptability

Technologies Used:
•	HTML5: For structuring the content.
•	CSS3: For styling, including media queries to ensure responsiveness.
•	JavaScript: For interactive elements like the playbar.
•	SVG Icons: For buttons and interface elements.

Future Improvements:
•	Add real audio functionality to control and play songs.
•	Backend integration for user authentication and playlist management.
