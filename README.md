# Spotify Clone
This project is a front-end clone of Spotify, built with HTML, CSS, and JavaScript. It features a responsive user interface, mimicking Spotify's design and functionality. Key features include:
1.	Responsive Design: Ensures the layout adjusts to different screen sizes, offering a seamless experience on both desktop and mobile devices.
2.	Custom Playlists Section: Displays several curated playlists, each represented by a card with an album cover, playlist name, and description.
3.	Interactive Playbar: Includes play, pause, and song control buttons, as well as a volume slider to simulate media control functionality.
4.	Login and Signup Buttons: Although non-functional, these buttons give the interface a more authentic look.
5.	Dynamic Icons and Styling: Uses SVGs and custom CSS for a polished look and feel.
The project primarily focuses on replicating the look of the Spotify web player, using CSS for styling and JavaScript for interactive elements.

# Features:
1.	Responsive layout for both mobile and desktop
2.	A sidebar for navigation (Home, Search, and Library)
3.	Playlist display with album covers and descriptions
4.	Playbar with song controls (previous, play, next)
5.	Buttons for signing up and logging in
6.	Dynamic media queries to ensure adaptability

# Technologies Used:
1.	HTML5: For structuring the content.
2.	CSS3: For styling, including media queries to ensure responsiveness.
3.	JavaScript: For interactive elements like the playbar.
4.	SVG Icons: For buttons and interface elements.

# Future Improvements:
1.	Add real audio functionality to control and play songs.
2.	Backend integration for user authentication and playlist management.
